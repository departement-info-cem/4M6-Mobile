# Installer Claude Code (CLI)

## 1. Installer

Windows (PowerShell) :

```powershell
irm https://claude.ai/install.ps1 | iex
```

Mac ou Linux :

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Ouvre un **nouveau** terminal, puis vérifie :

```bash
claude --version
```

Sur Windows, Claude Code a besoin de [Git pour Windows](https://git-scm.com/downloads/win).

## 2. Se connecter

```bash
claude auth login
```

Le navigateur s'ouvre : connecte-toi avec **ton compte Claude Pro** et autorise. Vérifie :

```bash
claude auth status
```

Au labo, refais `claude auth login` à chaque séance : le poste s'efface à la déconnexion.

Chez toi : Claude agit avec tes droits, sans toujours te demander. Lis d'abord [Une machine pour Claude](03-machine-pour-claude.mdx).

## 3. Tester

Dans le dossier de ton repo :

```bash
claude "Résume ce repo en 3 lignes"
```

Référence : [Installation de Claude Code](https://code.claude.com/docs/en/setup)
