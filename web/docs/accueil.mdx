# Accueil

Bienvenue au cours de 4M6 - Applications mobiles, version **hiver 2027**!

Tu apprendras à effectuer des appels réseaux, à développer et déployer un serveur, et à sécuriser l'ensemble.

Le projet fil rouge de la session : une application de **gestion des notes**, avec un serveur Spring Boot et deux apps Android, une pour les enseignants, une pour les étudiants.

Cette session, tu travailleras **systématiquement avec Claude Code** (Claude Pro, en terminal) sur les parties étiquetées 🤖, et **à la main** sur tout le reste ✍️. Le but : savoir piloter une IA de code **et** comprendre assez bien ce qu'elle produit pour la corriger, la défendre et s'en passer à l'examen.

Le contenu des cours ainsi que les énoncés de TP sont disponibles dans les onglets [Cours](cours/revision) et [Travaux Pratiques](tp/tp1).

Nous utiliserons aussi des [recettes](recettes/messages-erreur) pour des tâches spécifiques.

<Row>

<Column>

:::tip Avant chaque séance

Tu as du travail préparatoire pour découvrir la matière par toi-même. Il s'agira d'une page web à lire, d'une vidéo à suivre et/ou d'exercices à faire. Cela représente environ 2 heures de travail.

:::

</Column>

<Column>

:::info Séance

- Un rappel sur le calendrier et les remises
- Une causerie sur ce qui a été vu, sur ce qui n'a pas été compris
- Un retour individuel sur les exercices commencés
- Parfois des capsules de contenu supplémentaire
- Des exemples ou exercices corrigés en groupe

Ensuite, travail sur :

- Compléter et valider les exercices avec le professeur
- Poser des questions sur les exercices et travaux
- Avancer / compléter les travaux évalués

:::

</Column>

<Column>

:::caution IA - Claude Code

Chaque exercice porte une étiquette :

- <Etiquette type="claude" /> : à faire **avec Claude Code** (CLI, depuis ton repo d'exercices). Tu commites le résultat **et** un court `IA.md` : ton prompt / plan, ce que tu as corrigé, ce que tu n'as pas compris.
- <Etiquette type="main" /> : à faire **sans aucune IA** (ni Claude, ni Copilot, ni complétion IA). C'est ce qui prépare aux examens.

Les **tests papier** 📝 (10 minutes, aux ~3 séances) et les **examens** 💻 (intra et final, papier + machine) se font **sans IA**.

Le projet fil rouge (TP1, TP2, TP3) se fait avec Claude, mais chaque remise comprend une **défense à la main** : tu dois pouvoir expliquer et modifier ton code sans aide.

:::

</Column>

</Row>
